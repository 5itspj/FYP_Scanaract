## Setup Instructions

Before using this project, please ensure your local environment is set to **Python 3.11.15**. Then, install all required libraries by running `pip install` while referencing the code file.

## Dataset
Hybrid training dataset:
1,636 images (1,322 cataract; 650 normal) and an unseen test set of 33 images. Data sources include:
1.	Kaggle (https://www.kaggle.com/datasets/nandanp6/cataract-image-dataset?resource=download/)
2.	Roboflow (https://universe.roboflow.com/projectmaker/cataract-classification-iwlwt/)
3.	Original images captured via our hardware camera

YOLO 11 training dataset:  
[https://universe.roboflow.com/yolov11s-penn/pupil-image-segmentation/dataset/2](https://universe.roboflow.com/yolov11s-penn/pupil-image-segmentation/dataset/2)
